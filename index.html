9 dígito, A letra, * letra ou dígito, \ antes de um símbolo para usá-lo como texto fixo. O resto vira separador.

Use no seu projeto

Coloque o atributo data-mascara nos campos e chame iniciarMascaras():

<input data-mascara="cpf">
<input data-mascara="moeda" data-negativo>
<input data-mascara="AAA-9999">

<script type="module">
  import { iniciarMascaras } from './mascaras-br/src/index.js';
  iniciarMascaras();
</script>

Ou use as funções puras, no navegador ou no Node.js:

import { formatar, limpar } from 'mascaras-br';

formatar('12345678909', 'cpf');      // '123.456.789-09'
formatar('12abc34501de35', 'cnpj');  // '12.ABC.345/01DE-35'
limpar('R$ 1.234,56', 'moeda');      // '1234.56'
